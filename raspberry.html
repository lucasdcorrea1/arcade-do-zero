Instalar o RetroPie na Raspberry Pi

Do cartão vazio ao fliperama jogando. São os mesmos comandos que usamos no nosso fliperama, uma Raspberry Pi 3 com RetroPie. A referência completa, com scripts, está no repositório do projeto no GitHub.

EM BREVE

O app vai fazer esse setup completo. Estamos trabalhando para o RetroPie ROM Sender configurar a Raspberry Pi sozinho, direto do seu PC: Wi-Fi, SSH, emuladores e controles.

Enquanto isso, a instalação é manual, seguindo os passos abaixo. Depois que a Pi estiver pronta, o app já cuida de colocar os jogos pelo Wi-Fi. Conheça o app.

00

O que você precisa

  • Raspberry Pi 3 ou 4Com fonte de 5 V e 3 A. Fonte fraca trava o sistema.
  • Cartão microSDDe 16 GB ou mais.
  • Tela e controlesA tela HDMI do fliperama e os encoders USB dos dois jogadores.
  • Teclado USBSó para a primeira configuração.
  • PC na mesma redePara gravar o cartão e, depois, mandar comandos e jogos pelo Wi-Fi.
01

Grave o RetroPie no cartão

No PC
  1. Instale o Raspberry Pi Imager e coloque o cartão no PC.
  2. Em Dispositivo, escolha o modelo da sua Pi.
  3. Em Sistema operacional, abra Emulation and game OS e escolha RetroPie na versão do seu modelo.
  4. Em Armazenamento, escolha o cartão e grave. Tudo o que estiver no cartão será apagado.

Prefere fazer à mão? Baixe a imagem em retropie.org.uk e grave com o balenaEtcher.

02

Primeiro boot e controles

Na Raspberry Pi, com a tela e o teclado
  1. Coloque o cartão, conecte a tela, os controles e o teclado e ligue a Pi. Na primeira vez ela expande o cartão e reinicia sozinha.
  2. Na tela Welcome, segure um botão do controle do jogador 1 e mapeie as direções e os botões, um por um. Para pular um botão que não existe, segure qualquer botão.
  3. Para o jogador 2: menu Start → Configure Input e repita com o segundo controle.

Algum controle não responde? Aperte F4 no teclado para sair para o terminal e confira se a Pi reconheceu o encoder:

cat /proc/bus/input/devices | grep -i name

Para testar botão por botão:

sudo apt install -y joystick
jstest /dev/input/js0

Para voltar à tela de jogos, digite emulationstation.

03

Conecte no Wi-Fi e ative o SSH

Na Raspberry Pi, depois pelo PC
  1. Wi-Fi: no menu RetroPie da tela inicial, abra WiFi e escolha a sua rede.
  2. SSH, para mandar comandos do PC: rode o comando abaixo e vá em Interface Options → SSH → Yes.
sudo raspi-config

Descubra o IP da Pi:

hostname -I

No PC, abra o PowerShell e conecte. A senha padrão é raspberry:

ssh pi@IP_DO_PI

Troque a senha logo no primeiro acesso:

passwd

A partir daqui dá para colar todos os comandos pelo PC, sem teclado na Pi.

04

Atualize e ajuste o sistema

Pelo SSH 
sudo apt update && sudo apt upgrade -y

Teclado ABNT2, para aspas e acentos saírem certos. Escolha Generic 105-key PC → Portuguese (Brazil) → ABNT2 e reinicie:

sudo dpkg-reconfigure keyboard-configuration
sudo reboot

Fuso horário e saída de áudio ficam no mesmo menu do passo anterior, o sudo raspi-config.

05

Instale os emuladores

Pelo SSH

Cada sistema de jogos usa um emulador (core). Estes são os que usamos no fliperama:

SistemaPacotePasta de jogos
Arcade (CPS1, CPS2, Neo Geo)lr-fbneoroms/fba ou roms/arcade
Arcade (MAME 0.78)lr-mame2003-plusroms/mame-libretro ou roms/arcade
Game & Watchlr-gwroms/gameandwatch
sudo ~/RetroPie-Setup/retropie_packages.sh lr-fbneo
sudo ~/RetroPie-Setup/retropie_packages.sh lr-mame2003-plus
sudo ~/RetroPie-Setup/retropie_packages.sh lr-gw

Prefere menu? Rode o comando abaixo e entre em Manage packages:

sudo ~/RetroPie-Setup/retropie_setup.sh
06

Coloque os jogos

Do PC para a Pi

Pelo app (o jeito mais fácil): o RetroPie ROM Sender manda o jogo do PC para a pasta certa do emulador pelo Wi-Fi, já com a capa.

À mão pelo PC, trocando fba pela pasta do sistema:

scp jogo.zip pi@IP_DO_PI:~/RetroPie/roms/fba/

Por pendrive: crie uma pasta retropie na raiz do pendrive, espete na Pi e espere o LED parar de piscar. Depois copie os jogos para retropie/roms/SISTEMA no PC e espete de novo: a cópia é automática.

Arcade (fba, mame): não descompacte nem renomeie o .zip, porque o nome precisa bater com a versão do emulador. Use apenas jogos que você tem o direito de usar.

Para os jogos novos aparecerem na lista: menu Start → Quit → Restart EmulationStation.
